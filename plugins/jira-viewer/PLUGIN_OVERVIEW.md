Read your Jira Cloud issues without leaving bb. Saved views list your issues
from a local cache at once and refresh behind it. Issues read as documents,
with descriptions and comments converted to Markdown. Mention an issue with
`@ENG-123` to hand it to an agent as context. Agents get read-only search and
issue tools, plus the `bb jira-viewer` command. Uses an Atlassian API token,
stored as a secret on the bb server. Read-only.
